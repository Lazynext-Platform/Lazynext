**Title**: [Show] Lazynext — open-source AI video editor that edits your timeline via chat (MCP + Vertex AI)

**Body**:
I built Lazynext, a local-first AI video editor where AI agents edit a real multitrack timeline through conversation.

Instead of a chatbot that describes edits, Lazynext exposes 118+ editing tools to AI agents via MCP. Agents can create clips, add transitions, apply LUTs, generate images/video/speech/music, edit captions, and export — all through a proposal-based system where you approve each edit.

Tech: Electron, React, TypeScript, Remotion, Vercel AI SDK, Google Vertex AI (ADC auth, no API keys).

Free and open source (MIT). macOS, Windows, Linux.
